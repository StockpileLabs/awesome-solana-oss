## Contributing

PRs are welcome and encouraged. Every listed repository must be open source with a recognized license (MIT, Apache-2.0, GPL-3.0, BSD, MPL, or similar).

### What belongs

- Solana programs, clients, tools, infrastructure, or educational resources
- Actively maintained repositories that others can learn from or contribute to

### What does not belong

- Projects with a trivial Solana integration
    - Example: Multi-chain payments project that happens to let you transfer SPL tokens
- Low-effort vibecoded slop
- LLM skill files (or collections of them)

### How to add a project

1. Pick the single best-fit category. Do not list the same repository twice.
2. Add a row at the end of that category's table.
3. Use this format:

```md
| [Name](https://github.com/org/repo) | One-line description |
```

### PR checklist

- [ ] Valid open-source license
- [ ] Accurate, one-line description
- [ ] Working repository link
- [ ] Not a duplicate of an existing entry
- [ ] Table formatting matches the rest of the list
